# E-Service prompt collection

ชุดพรอมป์ต์ภาษาไทยสำหรับช่วยทำงานกับระบบ DEDE E-Service โดยใช้ ChatGPT ร่วมกับไฟล์ Excel และข้อมูลตัวอย่าง

## พรอมป์ต์

### 1. กรอกข้อมูลเครื่องจักรจาก Excel

> ช่วยกรอกข้อมูลเครื่องจักรในระบบ DEDE ตามตัวอย่างที่ฉันกรอกไว้ โดยใช้ข้อมูลจากไฟล์ Excel ที่แนบให้ ตรวจสอบหัวข้อ “ระบบที่ใช้พลังงาน” ให้ตรงกับระบบและหัวข้อในไฟล์ Excel เช่น ระบบปรับอากาศหรือระบบไฟฟ้า หากชื่อเครื่องจักรไม่มีตัวเลือกตรง ให้เลือกหมวดที่ใกล้เคียงตามแนวทางนี้: Chilled Water Pump ให้เลือกอุปกรณ์ปรับอากาศ/ทำความเย็นอื่น ๆ, Condenser Pump ให้เลือกปั๊มน้ำหล่อเย็น และ Cooling Tower ให้เลือกหอผึ่งน้ำเย็น กรอกสัดส่วนการใช้พลังงานเป็นตัวเลขเท่านั้น ไม่ต้องใส่เครื่องหมายเปอร์เซ็นต์ แต่ยังต้องกรอกข้อมูลสัดส่วนให้ครบ หากข้อมูลไม่ชัดเจนหรือมีข้อสงสัย ให้ถามฉันก่อนบันทึก

### 2. กรอกแผนฝึกอบรม DEDE

> ช่วยกรอกแผนฝึกอบรมในระบบ DEDE ตามตัวอย่างและข้อมูลในไฟล์ที่แนบให้ ใช้วันที่วันแรกของเดือนเป็นวันเริ่มต้น และวันสุดท้ายของเดือนเป็นวันสิ้นสุดตามเดือนที่ระบุในไฟล์ หากมีช่วงหลายเดือน ให้ใช้วันแรกของเดือนเริ่มต้นจนถึงวันสุดท้ายของเดือนสิ้นสุด ตรวจสอบชื่อหลักสูตร จำนวนผู้เข้าอบรม และผู้รับผิดชอบให้ตรงกับข้อมูลต้นทาง ก่อนบันทึกให้ตรวจสอบว่าระบบไม่ได้ค้างวันที่จากรายการก่อนหน้า หากพบข้อมูลไม่ตรงหรือมีความเสี่ยงที่จะบันทึกผิด ให้หยุดและถามฉันก่อน

### 3. กรอกแผนกิจกรรม DEDE

> ช่วยกรอกแผนกิจกรรมในระบบ DEDE ตามตัวอย่างและไฟล์ที่แนบให้ สร้างรายการตามกิจกรรมและช่วงเวลาที่กำหนดไว้ในไฟล์ โดยระบุวันที่เป็นวันแรกและวันสุดท้ายของเดือนที่เกี่ยวข้อง ตรวจสอบชื่อกิจกรรม ลำดับ จำนวนผู้เข้าร่วม และผู้รับผิดชอบให้ตรงกับต้นฉบับ หากกิจกรรมเดียวกันเกิดตลอดหลายเดือน ให้ใช้ช่วงวันที่ต่อเนื่องตามที่ระบุ แทนการสร้างรายการซ้ำ เว้นแต่ไฟล์กำหนดให้แยกเป็นหลายรายการ ก่อนบันทึกหรือลบรายการเดิม ให้ตรวจสอบผลกระทบและถามฉันหากมีความเสี่ยงหรือข้อมูลกำกวม

## วิธีใช้

1. เปิด ChatGPT และแนบไฟล์ Excel หรือภาพตัวอย่างที่เกี่ยวข้อง
2. คัดลอกพรอมป์ต์ที่ตรงกับงานไปวาง
3. ตรวจสอบข้อมูลและผลลัพธ์ใน DEDE ก่อนยืนยันการบันทึก
